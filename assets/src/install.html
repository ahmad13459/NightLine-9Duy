NIGHTLINE / RAILWAY DEPLOY IN FIVE STEPS ~10 MINUTES

نصب روی Railway در پنج گام

ONE SERVICE · ONE DOCKERFILE · ONE VOLUME · ONE TCP PROXY
NO TERMINAL NEEDED
01
مخزن را وصل کنید

مخزن را فورک کنید و در Railway گزینهٔ Deploy from GitHub را بزنید؛ Builder روی Dockerfile تنظیم می‌شود.

git clone <repo> && npm i
02
سرویس را بسازید

یک سرویس تازه با ایمیج Dockerfile؛ پورت داخلی ۸۰۸۰ است و همان پورت در Networking عمومی می‌شود.

PORT=8080
03
والیوم را وصل کنید

یک والیوم با مسیر /data اضافه کنید؛ پنل، کانفیگ‌ها و آمار مصرف همان‌جا می‌مانند.

DATA_DIR=/data
04
TCP proxy بسازید

یک TCP proxy به پورت داخلی 8443 وصل کنید؛ همهٔ پروتکل‌ها از همین یک پورت بیرون می‌آیند.

NL_TCP_PORT=8443
05
وارد پنل شوید

صفحهٔ /setup را باز کنید، حساب مدیر را بسازید، ورودی و کاربر اضافه کنید و لینک‌ها را بردارید.

https://<app>/setup
متغیرهایی که خودتان می‌گذارید
DATA_DIRمسیر والیوم برای سند داده و کانفیگ‌ها
NL_TCP_PORTپورت داخلی که TCP proxy باید هدف بگیرد
NL_XRAY_BINمسیر باینری Xray داخل ایمیج
NL_SINGBOX_BINمسیر باینری sing-box
NL_MAX_USERSسقف تعداد کاربران
آن‌چه Railway خودکار می‌دهد
PORTپورت پنل
RAILWAY_PUBLIC_DOMAINدامنهٔ HTTPS پنل
RAILWAY_TCP_PROXY_DOMAINمیزبان TCP proxy
RAILWAY_TCP_PROXY_PORTپورت عمومی TCP
RAILWAY_VOLUME_MOUNT_PATHمسیر والیوم
